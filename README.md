# taiji-site

taiji.zheng-he.top 站点源码 —— 太极模型数字讲解站与资产目录（K 层）。

## 部署现状（2026-11-11 核验）

- 线上生产环境由 Cloudflare Pages 项目 `taiji` 承载。
- Pages 项目未绑定 GitHub 仓库，历史生产部署类型为 `ad_hoc`（直接上传）。
- 向本仓库推送代码只负责源码留档，**不会自动更新线上网站**。
- 2026-11-11 比对发现，线上版本比本仓库新增知识资产及 K_pri 内容。部署前必须先核对并合并线上新增内容，禁止直接用旧仓库覆盖生产站点。
- 推荐流程：核对线上差异 → 本地检查 → 推送 GitHub → 预览部署验证 → 合并完整来源后部署生产环境。
